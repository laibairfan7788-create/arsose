\# ARSOS Website Instructions



Build a complete, production-ready MERN-stack website for ARSOS.



\## Sources



\- Read `docs/ARSOS-requirements.rtf` completely.

\- Use all relevant content from that document.

\- Use https://califorca.ae/ only as a design and structure reference.

\- Create an original ARSOS design. Do not copy Califorca branding or content.



\## Business sectors



Use these four detailed sectors:



1\. Cleaning Items

2\. Chemical Business

3\. IT Services

4\. Hotel Supplies



\## Required work



\- React frontend

\- Node.js and Express backend

\- MongoDB database

\- Home page

\- About page

\- Services page

\- Separate page for each business sector

\- Mission, vision, commitment and core-values sections

\- Why Choose Us section

\- Contact and enquiry form

\- Backend API for enquiries

\- Secure admin login

\- Admin dashboard for managing enquiries

\- Fully responsive mobile, tablet and desktop design

\- Professional animations and original branding

\- Form validation and error handling

\- Accessibility and SEO

\- `.env.example`

\- Tests

\- README and deployment instructions



Do not invent real addresses, phone numbers, emails, passwords or business

facts. Use clearly labelled placeholders when information is unavailable.



Do not add e-commerce, payments or fake products unless product information is

provided later.



Continue working until the complete project is implemented, tested and built.

Do not stop after planning or creating an initial scaffold.



Run linting, tests and production builds. Fix errors before declaring the work

complete.
